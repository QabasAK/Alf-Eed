# Start your own الف ايد

What you need to build a Jordanian Sign Language lexicon for your own field,
based on our engineering one.

## What's in the box

| Path | What it is |
| --- | --- |
| `PLAYBOOK.md` | The whole process, from picking a field to launching |
| `templates/terms.csv` | The term sheet: definitions, tags and media status |
| `templates/shoot_checklist.md` | What to prepare for filming a sign |
| `templates/university_one_pager.md` | A one-page pitch for your university |
| `.claude/skills/` | Five Claude Code skills that do the heavy lifting |

## Using the Claude skills

1. Install [Claude Code](https://claude.com/claude-code).
2. Unzip this folder and open it in Claude Code.
3. Ask in plain words, or call a skill by name:

| Skill | Ask something like |
| --- | --- |
| `/pick-your-number` | "We're doing pharmacy. What's our number?" |
| `/term-list` | "Draft the term list for pharmacy" |
| `/concept-video` | "Make the video for prime number" |
| `/sign-shoot` | "Prepare next Tuesday's shoot" |
| `/university-pitch` | "Write the pitch for our dean" |

`/concept-video` also needs [Manim](https://docs.manim.community/en/stable/installation.html).

## The one rule

**Signs come from Deaf signers.** Claude can draft definitions, animations and
paperwork. It must never invent, describe or approve a sign, and it won't.

# ابدأ مبادرتك: الف ايد

ما تحتاجه لبناء قاموس بلغة الإشارة الأردنية في تخصصك، استناداً إلى قاموسنا الهندسي.

- `PLAYBOOK.md`: الخطوات كاملة، من اختيار التخصص حتى الإطلاق.
- `templates/`: جدول المصطلحات، وقائمة تحضير التصوير، وصفحة تعريفية للجامعة.
- `.claude/skills/`: خمس مهارات جاهزة لـ Claude Code. افتح هذا المجلد في Claude Code واطلب ما تريد بكلماتك.

**القاعدة الوحيدة: الإشارات تأتي من الصمّ أنفسهم.** يساعد Claude في التعريفات والرسوم
المتحركة والأوراق، لكنه لا يخترع إشارة ولا يصفها ولا يعتمدها.
